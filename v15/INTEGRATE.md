# V15 → index.html integration (settings, map style, arrow, text size, route preference, saved places, Get Me Home)

Module: `v15/settings.js` (exposes `window.SNS`) + `v15/settings.css`. No accounts, no keys. State lives in
localStorage: `sn_settings` (style, arrow, text size, route pref), `sn_places` (shared with V9 search, see below),
`sn_prof_v15` (cached BRouter profile ids per host). Home stays on the device only.

Every hook below is an exact find → replace against the current index2.html (17:45 version: PROFILE_VER 'c6',
HOSTS fallback, V9 search with onQuery/localMatches). `v15/tools/build_test.py` applies these same 7 steps to
index2.html to produce `v15/test.html`, and asserts each anchor exists. Run it first; if an anchor
is missing, index.html has drifted.

## 1. Load the module
After `</style>` add:
```html
<link rel="stylesheet" href="v15/settings.css">
```
After `<script src="https://unpkg.com/maplibre-gl@4.7.1/dist/maplibre-gl.js"></script>` add:
```html
<script src="v15/settings.js"></script>
```

## 2. Map style from settings (V15a)
Find `style:'https://tiles.openfreemap.org/styles/dark'` and replace it with
`style:SNS.mapStyle('https://tiles.openfreemap.org/styles/dark')`

## 3. Overlays survive a style switch (V15a)
- Find `map.on('load',()=>{` and replace it with `map.on('style.load',()=>{if(map.getSource('route'))return;`
  (`setStyle(...,{diff:false})` wipes custom layers; this re-adds cyclosm, lanes and the route on every style load, and
  the existing `if(route)drawRoute();` redraws the route.)
- Replace **both** `layout:{visibility:'none'}` (cyclosm, lanes) with `layout:{visibility:lanesOn?'visible':'none'}`

## 4. Arrow color and size (V15b)
In meEl, find `stroke-linejoin="round"/></svg>';return d}` and replace it with
`stroke-linejoin="round"/></svg>';return SNS.decorateArrow(d)}`

## 5. Route preference profile (V15d)
In `routeOn(h,from,to,retry)`:
- Find `'&profile='+pr[mode]+` and replace it with `'&profile='+((await SNS.profileId(mode,h))||pr[mode])+`
- Find `if(!retry&&/profile/i.test(t)){await uploadProfiles(h);` and replace it with
  `if(!retry&&/profile/i.test(t)){SNS.resetProfiles(h);await uploadProfiles(h);`

For pref "fastest", `SNS.profileId` returns null, so the existing c6 ids are used unchanged. For "quiet" or "hills", it
fetches `profile/courier.brf`, patches it in the browser (the same code as `v15/profiles/*.brf`), POSTs it once per
host and caches the id. On any error it falls back to Fastest (`SNS.lastError`).

## 6. Saved places first in autocomplete (V15e)
- In suggest(): find `sugList=[...localMatches(q).slice(0,2),...rows].slice(0,6);showSugg(q)` and replace it with
  `sugList=SNS.mergeSaved(q,[...localMatches(q).slice(0,2),...rows].slice(0,6),c,6);showSugg(q)`
- In onQuery() (the short-or-bare-number branch): find `sugList=m.slice(0,6);showSugg()` and replace it with
  `sugList=SNS.mergeSaved(q,m.slice(0,6),me,6);showSugg()`
- In onQuery() (the >=3-char branch): find `sugList=localMatches(q).slice(0,2);showSugg();suggest(q)` and replace it with
  `sugList=SNS.mergeSaved(q,localMatches(q).slice(0,2),me,6);showSugg();suggest(q)`

Home is listed first, then favorites, then search rows. Rows within 25 m of a saved place are dropped. The existing
`#sugg` click handler routes in one tap (saved rows carry `ll`, `main` and `sub0`).

## 7. Init (Settings button, Get Me Home, sheets)
Immediately before `window._sn={` insert:
```js
SNS.init({map,darkStyle:'https://tiles.openfreemap.org/styles/dark',brouter:BR,photon:PHOTON,bbox:BBOX,profileUrl:'profile/courier.brf',getMe:()=>me,
  routeTo:(ll,name)=>{$('dest').value=name;$('sugg').style.display='none';$('dest').blur();setDest(ll,name)},
  replan:()=>{if(dest)plan(riding?'mode':false)}});
```
init inserts `#snrow` (a large **🏠 Get Me Home** button plus **⚙ Settings**) above the mode row. It also adds the
full-screen `#snsheet` (settings) and `#snedit` (place editor with Photon autocomplete), and applies the text scale
and arrow. Get Me Home routes home in one tap with no confirm. If Home is unset, it opens Set Home.

## Shared `sn_places` schema (important)
index2's V9 search already uses `sn_places = {saved:[{name,addr,ll}], recent:[...]}`. V15 uses the **same object**:
Home and favorites are entries in `.saved` with extra `{id, home:true|false}` fields that V9 ignores. SNS re-reads
storage on every operation and writes back only `.saved`, so V9's recents and "Save place" entries are kept and also
show up in Settings → Places. A legacy V15 array value is read as `{saved:array}`. This is covered by
`node v15/tools/interop.js` (PASS, `v15/shots/interop.json`).

## Profiles / rebase onto c6
- `v15/profiles/courier_{quiet,hills}_{scooter,ebike}.brf` are generated by `node v15/tools/gen_profiles.js` from
  `profile/courier.brf` (the current c6 file, 17:26). Each file is headed `REBASE-ON-C6`, and its changes are marked `# V15-PATCH`
  (and `# V15-TIGHTEN`, scooter only).
- `patchProfile` throws if an anchor is missing, if any cost would decrease (relax), or if any legal line changes
  (lines containing 10000, access=private, footway=sidewalk). If c6 changes again, re-run gen_profiles.js; it fails
  loudly instead of shipping a relaxed profile.
- quiet: primary ×3.0, secondary ×2.2, tertiary ×1.6, consider_traffic 0.6. Scooter only: cycleway 1.1 → 3.0, because R2
  otherwise preferred an off-street cycleway segment.
- hills: uphillcost 200, uphillcutoff 0.5. These trade some distance for less climbing.
- Proof: `BR=http://localhost:17778/brouter python3 v15/proof/check_v15.py` writes 42 geojson files plus summary_v15.json
  (R1-R5, H1-H2 × 3 prefs × 2 modes). Saved coordinates are rounded to about 1 m.

## Map style notes
- Dark: OpenFreeMap dark (unchanged).
- Light: **OpenFreeMap Positron** (`https://tiles.openfreemap.org/styles/positron`). The spec'd CARTO raster
  `basemaps.cartocdn.com/light_all/{z}/{x}/{y}.png` now returns an "API KEY REQUIRED carto.com/basemaps/apikey"
  placeholder for every tile, with or without a Referer (checked 2026-10-30), so it is not keyless. A keyless CARTO
  alternative that worked on 2026-10-30 is `https://basemaps.cartocdn.com/gl/positron-gl-style/style.json`. To use it,
  swap `STYLES.light.url` in settings.js.
- Satellite: Esri World_Imagery raster, credit "Esri, Maxar, Earthstar Geographics".

## Integration notes (as shipped in index.html)
- `attributionControl:false` in the Map options: SNS owns attribution. `applyCredit()` re-adds a compact
  AttributionControl on every style switch with the per-style credit (dark/light: "© OpenFreeMap © OpenMapTiles
  © OpenStreetMap contributors"; satellite: the Esri source credit "Esri, Maxar, Earthstar Geographics" plus OSM
  for search/routing data). `liftCtl()` keeps the bottom map controls above `#bottom` so the credit is never hidden.
- `map.on('error')` ignores tile errors from the external CyclOSM raster (Lanes layer) instead of logging them.
- Test: `v15/tools/v15full.js` (54 checks, writes `v15/proof/v15_integrated_check.json`),
  videos: `v15/tools/rec_videos.js`, strip: `v15/tools/contact_strip.py`.
